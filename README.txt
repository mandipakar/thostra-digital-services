THOSTRA DIGITAL SERVICES WEBSITE
================================

Files:
- index.html       Home
- about.html       About
- services.html    Service catalogue
- portfolio.html   Portfolio overview
- support.html     IT support information
- contact.html     Contact and WhatsApp enquiry form
- styles.css       Responsive styling
- script.js        Mobile navigation, year and WhatsApp form
- assets/          Thostra logo

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

PUBLISH ON GITHUB PAGES
1. Create a new GitHub repository, for example thostra-digital-services.
2. Upload all files and the assets folder (keep the folder structure).
3. In repository Settings > Pages, select Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish the site.

IMPORTANT BEFORE PUBLIC LAUNCH
- Confirm the official business email address and add it to contact.html.
- Confirm whether both phone numbers should receive WhatsApp enquiries.
- Replace demonstration portfolio descriptions with genuine work and verified case studies.
- Review all service claims, pricing and project capabilities before advertising.
- The site currently uses the supplied Thostra logo as the brand image.
